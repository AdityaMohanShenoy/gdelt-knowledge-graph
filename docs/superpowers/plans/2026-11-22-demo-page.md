# Demo Page (`/demo`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A presentation page at `/demo` that tells the project's story with live numbers and ends with live causal querying.

**Architecture:** One self-contained `frontend/demo.html` (inline CSS/JS) served by a new FastAPI route. Live counters come from a new `/api/explain/stats` endpoint computed from the loaded graph; answers come from the existing `/api/explain` and `/api/consequences`. Saved answers for featured questions ship in `frontend/demo-featured.json`, generated from the real query engine.

**Tech Stack:** FastAPI (`app.py`), `causal_query.py`, vanilla JS, d3 v7.9.0 from cdnjs for the network panel, pytest.

**Spec:** `docs/superpowers/specs/2026-11-22-demo-page-design.md`

## Global Constraints
- Never re-add pandas; endpoints deterministic (sorted output, no ties left to chance).
- Every number shown is from the graph or the measurement reports (`docs/measurements/scale_2000.md`, `final_evaluation.md`).
- Look: "Night observatory" — dark navy ground, amber and green figures; projector-legible (body ≥ 18px, headline counters ≥ 64px).
- Invoke the frontend-design skill before writing `demo.html`.
- Respect `prefers-reduced-motion`; keyboard: `1`–`6` jump to sections, `/` focuses the question box.

## Review Focus
- **Live API fails mid-talk** → a featured question still renders from `demo-featured.json`, with a small "saved answer" label; a free-typed question shows a plain error, not a blank panel.
- **Question matches several stories (`status: "clarify"`)** → show the options as buttons that re-ask with `cluster=`.
- **Question matches nothing (`status: "no_match"`)** → friendly message plus the featured chips.
- **d3 fails to load** → the network panel hides; chains still render.
- **Implied-links toggle** → passing `implied=true` changes both the answer and the counters' "hidden" note, matching the main dashboard.
