News says why. Databases only say what.

GDELT logs millions of events from the world's news, but never the reason they happened. This project reads the articles behind 2024's Indian protests and turns the reasons they state into a causal graph you can question, with every link quoted from its source.

Event codes alone cannot tell a cause from a coincidence.

We first tried the obvious shortcut: score possible causes from GDELT's own fields (who, where, which event code, how many days apart). Then we fed it pairs of events that had nothing to do with each other.

Real cause-and-effect pairs
3.8%
Shuffled, unrelated pairs
4.0%

It flagged random pairs as often as real ones, and 0 of the 322 causes it proposed was a cause the articles actually support.

Share of pairs given the scorer's "pattern" grade. Source: project negative-control test (docs/measurements/negative_controls.md).

So we read the articles, and kept only what they say.

Every field is copied word for word from the text. A link is kept only when the article states it, and a second, independent check must agree before it enters the graph.
